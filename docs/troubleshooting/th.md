# แก้ปัญหา

missing: ติดตั้ง executable ที่ doctor ระบุหรือแก้ PATH; engine_version_mismatch: ใช้เวอร์ชัน exact ตามไฟล์ pin

timeout/log_limit: เปิด log ตาม path Evidence แก้เหตุที่ค้างก่อนเพิ่มงบ; import_errors/missing_imports: ดู import log และใช้ Godot import ใน worktree; runner จะ retry แบบไม่ลบ cache อัตโนมัติ

display_unavailable: เปิด graphical session; skipped ไม่เท่ากับผ่านเมื่อเป็น required check ผล SCRIPT ERROR แม้มี summary ผ่านยังถือว่าล้มเหลว ใน sandbox ที่บล็อก macOS editor settings ต้องรันด้วยสิทธิ์ที่เหมาะสม ไม่กรอง error ทิ้ง
