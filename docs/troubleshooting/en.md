# Troubleshooting

missing: install the executable reported by doctor or fix PATH. engine_version_mismatch: use the exact pinned version.

timeout/log_limit: inspect the Evidence log and fix the hang before raising limits. import_errors/missing_imports: inspect import logs and retry the editor import in your worktree. The runner retries without deleting caches automatically.

display_unavailable: use a graphical session. A required skipped check is not success. SCRIPT ERROR fails even after a passing summary. If a macOS sandbox blocks editor settings, run with appropriate permission rather than suppressing errors.
