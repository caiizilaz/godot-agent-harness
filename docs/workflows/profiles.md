# Capability profiles

Planner: define measurable acceptance and context pointers. Implementer: edit owned files and demonstrate checks. Visual reviewer: inspect native output, layout and accessibility. Integrator: assess cross-system diffs and full evidence. Any suitable agent or person may hold a role. Choose by available tools and observed results, not a permanent vendor ranking. One agent may hold all roles. Delegate only when independent work outweighs context/handoff cost. gstack is optional; no provider account is required.
